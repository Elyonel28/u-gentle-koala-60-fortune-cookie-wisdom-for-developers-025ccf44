# Fortune Cookie Wisdom for Developers

One original fortune-cookie line for a software developer, built for
make.fun's **Fortune Cookie Wisdom for Developers** bounty ($2, top two
places split $1.18 / $0.82).

## The fortune

> The function you name 'temp' will outlive every function you name 'final'.

74 characters — inside the gate of 1 to 120 characters.

## Why this line

Every developer has lived it: the throwaway hack meant to last a day
becomes load-bearing, while the carefully named `final` code gets
rewritten within the month. The line is one short, balanced sentence
that lands in a single breath, says something true about a developer's
day, and turns that truth around — the names we give our code promise
the exact opposite of what happens to it. Read it twice and the twist
lands: `temp` and `final` are both lies, in opposite directions.

## Run it

`main.ts` runs on Node 22 with the standard library only and writes the
fortune to `/output/entry.txt`:

```sh
node main.ts
```
